Здесь работает .gitignore
0 - open Git Bash here - в локальном репозитории
1 - git init
2 - git status
3 - git check-ignore -v 
4 - git commit -m "Initial commit"
5 - git add -A
6 -  git push -u origin main (Отправка данных из локального репозитория на удалённый GitHub)
